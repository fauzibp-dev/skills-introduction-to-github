# 4-week practice plan

Purpose: build skills without testing live NASA systems as a first exercise.

## Week 1: HTTP + web foundations
- Requests/responses, methods, parameters, cookies, sessions, authn vs authz
- Learn browser devtools and Burp Suite basics
- Practice only against local apps or explicit security-training labs

## Week 2: Web Security Academy
- Work through introductory labs for access control/IDOR, XSS, and SQL injection
- Write a 5-line explanation of root cause, exploitation preconditions, and remediation for each lab
- Track completion based on actual lab results, not guesses

## Week 3: Local vulnerable app
- Run OWASP Juice Shop locally
- Explore the app's designed challenges, avoiding any third-party system
- Practice a sanitized bug report for a lab vulnerability

## Week 4: Disclosure workflow
- Read NASA's current VDP and the live Bugcrowd brief
- Confirm current scopes manually and record permission checks
- Rehearse writing a professional, reproducible English-language report from a lab
- Decide whether ready to research permitted NASA targets; do not run indiscriminate scans

## Honest portfolio policy
Publish only lab write-ups and authorized, already disclosed research. Only claim NASA recognition if NASA has actually issued it.
